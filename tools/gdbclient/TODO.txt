# GDB Client MCP 开发计划

## 项目介绍
GDB Client MCP 服务器是一个用于与 GDB 服务器交互的 MCP 服务器，支持通过 GDB 的 load 和 restore 命令加载 ELF 文件和内存快照，用于分析 crash 原因。

## 使用技术
- Python 3.8+
- pygdbmi 库（用于与 GDB 交互）
- MCP 协议（与 Trae 通信）
